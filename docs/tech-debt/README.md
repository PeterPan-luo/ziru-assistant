## 详细债务

### TD-001: 用户认证
**问题**: 当前使用硬编码的临时用户 ID
**影响**: 无法支持多用户
**解决方案**: 集成 NextAuth.js
**优先级**: 高（Phase 2 前必须解决）

### TD-002: 测试覆盖
**问题**: 缺少单元测试和集成测试
**影响**: 代码质量无法保证
**解决方案**: 添加 Jest/Vitest 测试
**优先级**: 高

### TD-003: 错误处理优化
**问题**: 错误信息不够友好
**影响**: 用户体验差
**解决方案**: 统一错误处理中间件
**优先级**: 中

### TD-004: 日志系统
**问题**: 缺少结构化日志
**影响**: 难以调试和监控
**解决方案**: 集成 Pino/Winston
**优先级**: 中

### TD-005: 时间解析增强
**问题**: 部分复杂时间表达无法解析
**影响**: 用户需要换种说法
**解决方案**: 增强 parseChineseTime 函数
**优先级**: 低
