## 层级依赖规则

```
Types → Lib → Tools → Agents → API → App
  │       │       │        │       │      │
  └───────┴───────┴────────┴───────┴──────┘
           依赖方向：从左到右
```

**规则**：
- Types 可被任何层引用
- Lib 不能依赖 Agents
- Tools 不能依赖 API
- 严格遵守单向依赖

## 关键设计决策

| 决策 | 选择 | 原因 |
|------|------|------|
| Agent 框架 | Vercel AI SDK | 开箱即用，流式支持 |
| 大模型 | GLM-5 | 中文理解优秀，成本低 |
| 数据库 | PostgreSQL | 成熟稳定，支持 pgvector |
| ORM | Drizzle | 轻量，类型安全 |
