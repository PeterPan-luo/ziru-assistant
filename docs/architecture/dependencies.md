## 依赖规则

### ✅ 允许
- App → API, Agents, DB
- API → Agents, Tools, DB
- Agents → Tools, Lib
- Tools → DB, Lib
- Lib → Types (外部库)

### ❌ 禁止
- Lib → Agents
- Tools → API
- DB → Agents
- 任何层 → App（表现层）

---

## 版本锁定

关键依赖版本锁定策略：
- **React/Next**: 使用最新稳定版
- **Drizzle ORM**: 锁定次版本
- **AI SDK**: 锁定主版本
