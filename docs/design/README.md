## UI 组件

### 聊天界面
- **消息气泡**：用户消息靠右蓝色，助手消息靠左灰色
- **输入框**：底部固定，支持多行输入
- **工具调用展示**：显示 Agent 调用的工具和结果

### 日历视图
- **月视图**：7x6 网格，显示事件概要
- **事件指示器**：有事件的日期显示小圆点
- **今日高亮**：当天日期蓝色背景

## 交互规范

### 确认对话
- 删除日程：弹窗确认
- 批量修改：显示预览后确认
- 敏感操作：需要二次确认

### 错误处理
- 网络错误：显示重试按钮
- 解析失败：友好提示，建议替代方案
- 工具调用失败：显示具体错误信息
