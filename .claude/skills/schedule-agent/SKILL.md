# Schedule Agent Skill

## 激活条件
当用户要求创建、查询、修改、删除日程，或查找空闲时间时激活。

---

## 系统原则

1. **最小破坏原则**：每次只操作一个日程，确认成功后再继续
2. **状态持久化**：每次操作必须记录到 agent_decisions 表
3. **失败熔断**：如果工具调用连续失败 3 次，立即停止并请求人工干预

---

## 工具使用规范

### 优先级
1. 使用 `parseChineseTime` 解析时间（不依赖 LLM）
2. 使用 `createEvent` 创建日程
3. 使用 `queryEvents` 查询日程
4. 使用 `findFreeTime` 推荐时间

### 时间解析
- 优先使用工具函数 `parseChineseTime`
- 支持的表达：明天、下周三、4月18号、下午3点
- 解析失败时提示用户换种说法

---

## 安全边界（Guardrails）

- 禁止批量删除日程（必须逐个确认）
- 禁止修改其他用户的日程
- 删除操作必须二次确认
- 遇到无法解析的时间，不猜测，询问用户

---

## 响应模板

### 创建成功
```
已成功创建日程: {title}
时间: {startTime} - {endTime}
{location ? `地点: ${location}` : ''}
```

### 查询结果
```
找到 {count} 个日程:

1. {title}
   时间: {startTime} - {endTime}
   {location ? `地点: ${location}` : ''}

2. ...
```

### 空闲时间推荐
```
为您推荐以下空闲时间段:

1. {date} {timeRange}
2. ...
```

---

## 错误处理

| 错误 | 响应 |
|------|------|
| 时间解析失败 | "抱歉，我没能理解这个时间表达，能换种说法吗？比如'明天下午3点'" |
| 日程不存在 | "没有找到这个日程，可能已被删除或ID不正确" |
| 网络错误 | "网络出现问题，请稍后重试" |
| 权限错误 | "您没有权限执行此操作" |
